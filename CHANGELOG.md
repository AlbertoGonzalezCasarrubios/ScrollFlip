# Changelog

## 1.1.0 — 2026-11-17

### New
- **Windows-style autoscroll** (optional, off by default). Click the wheel and move the mouse to scroll in any direction; any click stops it. Wheel clicks on links still open them in a new tab. A *Hold and drag* mode is also available.
- **Back / Forward on side buttons 4 and 5** (optional, off by default). Uses the swipe-between-pages gesture in Safari, Finder and other Apple apps, so it works with any keyboard layout. Includes a *Swap buttons* option.
- **Try it tab:** simulated side-button clicks, an autoscroll test area and a live link-cursor indicator.
- **New black-and-blue icon.**

### Improved
- The extra event taps (side buttons, wheel click) exist only while their option is on, and the health check keeps them alive after sleep or user switches.
- Builds compile from a snapshot, so cloud-synced folders can't break the build.

## 1.0.0 — 2026-11-16

- Reverse the mouse wheel without touching the trackpad.
- Adjustable wheel speed, live *Try it* tab, English and Spanish UI.
- Self-healing event tap, launch at login, About panel.
- Universal binary, sandboxed, with no network access.
